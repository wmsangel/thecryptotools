# IG автопостинг — запланированная задача

Публикация постов в Instagram **@thecryptotools** автоматически, через Chrome владельца.

- **Задача:** `thecryptotools-ig-autopost` (в приложении → раздел «Scheduled»).
  Файл: `~/.claude/scheduled-tasks/thecryptotools-ig-autopost/SKILL.md`.
- **Расписание:** ежедневно ~11:20–11:24 (локальное, Бишкек). Слот закреплён, чтобы
  проекты сети не дрались за Chrome.
- **Что делает (1 пост за запуск):** берёт пост дня из `posts.js` по дню недели →
  пропускает, если это сторис (их постит владелец вручную из бота) или если id уже
  в `ig-posted.json` → **проверяет, что активен именно @thecryptotools** (иначе
  переключается; если не подтвердить — ABORT) → публикует через IG-веб «Create»
  (карусель = альбом) → пишет id в `ig-posted.json`, коммит+пуш → короткий отчёт.
- **Журнал:** `social/ig-posted.json` — опубликованные id (дедуп, без повторов).
- **Раздача по форматам:** посты/карусели → этот автопостер (Chrome); сторис →
  Telegram-бот (`telegram-daily.mjs`, сторис нельзя загрузить через веб).

## Разовая настройка (владелец)
Открыть страницу задачи в приложении → **Run now** один раз, чтобы предодобрить
управление Chrome (иначе будущие автозапуски могут вставать на запросе прав).
Приложение должно быть открыто в момент запуска (иначе задача выполнится при
следующем старте приложения).

## Композер IG (late 2026) — особенности (в промте задачи)
- Поток `/create/style/` → `/create/details/`, выбора пропорций нет. Полноэкранный
  предпросмотр может выглядеть обрезанным — правда в миниатюре на экране деталей
  (проверять через zoom; наши слайды 1:1, реально не режется).
- `input[type=file]` не виден в дереве доступности → проставить ему aria-label
  через JS, потом file_upload.
- Поле подписи — textarea с aria-label «Write a caption…» → form_input.
- Аккаунт проверять ДВАЖДЫ: в начале и ПРЯМО перед «Share» (соседние задачи в том
  же Chrome могут переключить аккаунт на лету). FB-тумблер — глазами (zoom).
- Escape в экране подписи = «Discard post?»; клики — по ref из find.

## Надёжность
IG-веб-постинг хрупкий (модалки, шаги). Промт задачи защитный: при любой
неоднозначности (не тот аккаунт, неожиданный шаг) — прерывается без публикации,
на чужой аккаунт не постит, один и тот же пост дважды не шлёт. Первые запуски
стоит проглядеть в отчётах задачи.
