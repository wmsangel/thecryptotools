# Соцсети — модуль TheCryptoTools

Готовый к постингу контент-модуль: генератор брендовых слайдов, недельный контент-план, хаб-страница и TG-напоминание. Язык — **EN** (сайт англоязычный).

**Контент-хаб (приватный артефакт):** https://claude.ai/artifact/GG5ZAEN2QpELC2MrexmrJP — заходишь, берёшь слайды/текст/хэштеги на сегодня, постишь.

## Что где

| Часть | Файл / место |
|---|---|
| Генератор слайдов | `scripts/social/generate-slides.mjs` (@vercel/og → PNG, IBM Plex Sans, брендовый графит+teal) |
| Контент-план (данные) | `scripts/social/content-plan.mjs` (7 постов/неделя) |
| Слайды (сгенерированы) | `scripts/social/out/*.png` (git-ignored, перегенерируются) |
| Хаб-страница | артефакт (ссылка выше) |
| TG-напоминание | `scripts/social/tg-daily.mjs` (ждёт твои TG-креды) |

## Как пользоваться
1. `node scripts/social/generate-slides.mjs` (или `--scale 2` для retina) → слайды в `scripts/social/out/`.
2. Публикую их в хаб-артефакт (через `files`), обновляю хаб на тот же URL.
3. Ты заходишь в хаб → сегодня подсвечено → долгий тап по слайду («Сохранить в Фото») → копируешь caption+хэштеги кнопкой → постишь в Instagram (+ Pinterest). Галочка «posted» помнится.
4. Правка плана = правишь `content-plan.mjs`, перегенерируешь, перепубликовываешь хаб.

> Сохранить картинку из артефакта: кнопки «Скачать» нет (песочница блокирует) — **долгий тап → «Сохранить в Фото»** (телефон) / правый клик (ПК). В будущем CRM будет честная кнопка.

## Какие сети и почему (решение под проект)
- **Pinterest — старт №1 (рекомендую).** Это ПОИСКОВИК: пины живут месяцами и тянут трафик сами — лучший фит под нашу «только органика» + сильный SEO-уклон. Карусели/чек-листы переливаются в вертикальные пины почти без правок. Описание пина — с ключами («crypto tax calculator», «grid bot backtest»).
- **Instagram — лента + сторис**, вручную из хаба. Основной визуальный канал, но без встроенного поиска растёт медленно.
- **Telegram — сеть/ops.** `tg-daily.mjs` шлёт дневное «сегодня по плану» в приватный ops-канал (напоминание). Опционально — публичный бренд-канал (ASO-имя/описание). Низкий discovery, но сетевой стандарт.
- **Threads** — бесплатный кросс-пост текста из IG (EN), низкие усилия — стоит включить.
- **НЕ берём:** Дзен / VK (это RU-аудитория, у нас EN-сайт). Видео (Reels/TikTok/Shorts) — пока нет (контент = слайды).

Честно: IG/TG без поиска растут медленно. При нашем сильном SEO стратегически **начинать с Pinterest + Instagram**, TG как сетевой канал, Threads как бесплатный кросс-пост.

## Telegram — ДЕЙСТВИЕ ВЛАДЕЛЬЦА (не могу автономно)
Создать TG-канал/бота можно только из твоего Telegram. Шаги — в шапке `scripts/social/tg-daily.mjs`: создать канал (ASO-имя/описание) → @BotFather `/newbot` → токен → бот-админ в канал → положить `~/.config/seo-stats/telegram-bot-token.txt` + `telegram-ops-chat.txt` → повесить `tg-daily.mjs` на launchd/cron (09:00). После этого дневные напоминания идут сами.

## Рамки
Честный тон без кликбейта и выдумок. Налоговые посты — «(Not tax advice)». erid/маркировка — только для платной рекламы, к органике не относится. Бренд-токены: публичный teal-градиент сайта (слайды) + графит-#3a5bb0 (хаб-страница, как витрина).
